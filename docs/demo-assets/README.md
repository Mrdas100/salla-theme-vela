# VELA Demo Asset Kit

هذه الصور أصلية ومولّدة خصيصًا لعرض ثيم VELA. تستخدم في متجر العرض عبر محرر سلة، وليست صورًا من ثيم «عالي» أو من متاجره.

## التوزيع المقترح

| الملف | المقاس | الاستخدام |
|---|---:|---|
| `vela-campaign-hero.png` | 1774×887 | Drop Hero / واجهة الحملة الرئيسية |
| `vela-lookbook-women.png` | 1122×1402 | Lookbook — مجموعة النساء |
| `vela-lookbook-men.png` | 1122×1402 | Lookbook — مجموعة الرجال |

## نصوص تجريبية مقترحة

- العنوان الرئيسي: **حركة تصنع حضورك**
- النص: **تصاميم يومية بأداء تقني، صنعت لتتحرك معك.**
- الزر الأساسي: **تسوّق المجموعة**
- الزر الثانوي: **اكتشف الجديد**
- بطاقة النساء: **أداء بلا تنازل**
- بطاقة الرجال: **أساسيات تتحرك معك**

يفضل ضغط الصور إلى WebP/AVIF عند تجهيز متجر العرض، مع الاحتفاظ بهذه الملفات كنسخ مصدر عالية الجودة.
