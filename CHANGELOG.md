# Changelog

All notable VELA-specific changes are documented here. Platform baseline changes inherited from Salla Theme Raed are retained in `docs/UPSTREAM_CHANGELOG.md`.

## [0.2.0] — 2026-09-27

### Added

- Responsive image/MP4 support for the VELA Media Hero.
- Brand Story component with image/video, CTA, and trust metrics.
- Merchant-configurable dark/light colors with a customer toggle and saved preference.
- Reduced-motion handling for campaign video.
- Competitive benchmark and original demo imagery.

### Changed

- Restyled Twilight product tabs to use the VELA visual language.

## [0.1.0] — 2026-09-27

### Added

- VELA product specification, architecture, testing, and release criteria.
- Arabic-first editorial-performance design system and merchant tokens.
- Drop Hero, Flash Sale, Lookbook Mosaic, and FAQ home components.
- Product Quick View with keyboard focus management.
- Recently viewed products using local browser storage and native Salla rendering.
- Category campaign hero and “Complete the look” related-products treatment.
- Theme schema contract checks and production build workflow.

### Changed

- Rebranded the official Theme Raed baseline as the VELA development theme.
- Restyled header, footer, product cards, product pages, and listing pages.

### Known validation work

- Component editor persistence and live Salla data require a connected Partners demo store.
- The inherited Sass import deprecations and base app bundle budget remain performance follow-up items.
